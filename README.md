# Python-Chatbot
# 🤖 Offline AI FAQ Chatbot

This is an intelligent chatbot that answers user queries using a `.docx` FAQ document — all processed locally using sentence embeddings and FAISS vector search.

## 🚀 Features

- Uses `SentenceTransformers` for semantic understanding
- Fast response with FAISS vector search
- GUI powered by Gradio
- Runs fully offline (no OpenAI or API calls)

## 🧠 Technologies

- Python
- FAISS
- SentenceTransformers
- Gradio
- DOCX parsing
